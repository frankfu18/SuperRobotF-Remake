# 配置验证清单

## 源结构检查

- 配置源文件位于 `cfg/` 对应模块目录。
- 新模块已加入总入口 XML。
- XML 定义顺序符合目标项目规则。
- enum、bean、config、字段和文件命名一致。
- `ref`、跨模块类型和集合类型可以被生成器解析。
- 主键、外键、枚举值和 map 键合法且唯一。

## xlsx 检查

- 表头、数据列和 XML 字段顺序一致。
- bean、list、map、array 和多态 bean 展开方式与项目已有表一致。
- 保存后重新读取工作簿，关键单元格值和类型正确。
- 渲染受影响区域，确认没有错列、隐藏数据、异常换行或不可读中文。
- 没有 `????`、替换字符或乱码文本。

## 生成检查

- 配置生成命令成功结束，没有忽略警告或错误。
- 生成 C# 中存在预期类型、字段和访问方法。
- 运行时配置数据已更新。
- 重命名或迁移后没有旧类型、旧访问方法和旧生成文件残留。
- 没有直接手改生成文件。

## 编译与运行时检查

- 编译目标项目真实使用配置的程序集。
- 运行时能按合法 ID 读取配置。
- 缺失 ID、空集合、无效引用和异常数值不会造成未处理异常。
- 新增默认值不会意外改变旧数据行为。
- 涉及战斗时，验证配置从入口到实体/组件初始化，再到规则结算或表现读取的完整链路。

## 交付前搜索

根据本次改动搜索：旧类型名、旧字段名、旧 xlsx 文件名、旧访问方法、临时占位、`TODO` 和乱码。只处理本次影响范围，不清理无关历史问题。

交付时说明实际执行过的生成命令、编译命令、行为验证和未执行项。
