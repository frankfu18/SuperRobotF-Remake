# Excel 数据规范

## 编辑前检查

1. 使用表格工具读取工作簿的工作表、有效区域、公式、合并单元格和前几行数据。
2. 对照对应 XML，建立“字段定义到实际列”的映射。
3. 检查同一模块中相似表格的 list、map、bean 和多态 bean 填写方式。
4. 已有表出现额外说明行、特殊展开区或历史格式时，保留其实际结构；不要强制改造成通用两行表头。

## 新表默认表头

目标项目没有更具体约定时，新建 xlsx 使用两行表头：

- 第 1 行填写中文说明，第一列以 `##` 开头。
- 第 2 行填写 XML 字段名，第一列以 `##` 开头。
- 普通字段在两行中都占一列。
- 不需要的字段和备注列不要添加。
- 确需备注时，默认放在 `id` 后面，除非项目已有不同规则。

全局 `mode="one"` 表只保留配置字段，不额外增加 `id`。

## bean 展开

- bean 类型列填写实际 bean 或子 bean 名称。
- bean 参数紧跟类型列，顺序与 XML 定义一致。
- 默认情况下，bean 展开参数列的中文说明和字段名保持为空，除非目标项目已有明确表头规则。
- 多个子 bean 共用展开区域时，每一行只按该行选择的子 bean 解释后续列。
- 修改 bean 字段顺序后，必须同步检查所有使用该 bean 的工作簿。

## list、map 和 array

- 不凭经验发明括号、换行或分隔符；先读取目标项目已有同类型表格的真实编码方式。
- list 中每个元素、map 中每个键值对、嵌套 bean 中每个字段，都必须与 XML 类型和顺序对应。
- map 的键必须唯一，并校验等级、ID 等业务范围。
- 集合为空时使用项目生成器认可的空值表达，不能随意填 `0`、`None` 或空字符串代替。
- 改动嵌套集合后，抽查首项、中间项、末项和空集合，防止终止标记或展开列错位。

## 表格工具要求

- 使用结构化表格工具编辑 xlsx，不用字符串拼接或文本替换修改压缩包内部 XML。
- 优先使用当前环境提供的电子表格 Skill 或项目既有表格脚本。
- 保存后重新读取工作簿，验证单元格值、数据类型、工作表名称、合并区域和有效范围。
- 渲染受影响区域进行视觉检查，确认中文、列宽、换行、空列、展开区域和长文本可读。

## 数据质量

- 主键必须唯一，外键必须能在目标配置中找到。
- 枚举值、类型名和 bean 名必须与 XML 精确一致。
- 数值单位按策划规则填写，例如万分比、百分比、毫秒或秒，不能在表格中混用。
- 文本统一使用 UTF-8 可读中文，检查 `????`、替换字符和常见乱码片段。
- 不覆盖用户在同一工作簿中的无关修改。
